## Important Notes

1. **Security:** These demo accounts use simple passwords for demonstration purposes only. In a production environment, use strong, unique passwords.
2. **Data:** All demo data is fictional and intended for testing and demonstration purposes.
3. **Reset:** To reset demo data, re-run the `demo-data-seeding.sql` script.
4. **Cleanup:** To remove demo data, manually delete the records or use a cleanup script.
